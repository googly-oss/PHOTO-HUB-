# PHOTO HUB — Demo #5
Premium photography studio website demo for PHOTO HUB, Guwahati, Assam.

- Established: 14 April 2016
- Official Facebook: https://www.facebook.com/DjPhotography123/
- Uses only the supplied PHOTO HUB photographs.
- Includes responsive editorial gallery, category filters, lightbox, and a reel with original calm instrumental audio.

## Deploy
Upload the contents of this folder to a GitHub repository and enable GitHub Pages from the `main` branch / root.
